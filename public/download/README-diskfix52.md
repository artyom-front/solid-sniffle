# diskfix52 — разблокировка деплоя v1.0.51 (диск VPS) + профилактика

**Диагноз (07.10.2026, ран v1.0.51):** `docker compose pull` падал на
`no space left on device` — извлечение слоёв в overlayfs. Сеть в порядке
(слои докачивались до конца), диск — переполнен: теги образов
`…:1.0.44…1.0.50` копились (~0,5–1 ГБ каждый), а чистка `docker image
prune --filter label=…` из v1.0.45 была **no-op** (label есть только у
образов, собранных compose; наши собираются в CI). Прод не тронут:
деплой упал ДО бэкапа/миграций/up — контейнеры 1.0.50 работают,
`.deploy/current` = 1.0.50.

## 1. Разблокировать СЕЙЧАС (SSH на VPS)

```bash
df -h                        # что переполнено (обычно /)
docker system df             # сколько жрут образы
docker image prune -a -f     # старые теги приложения; 1.0.50 и
                             # postgres:16-alpine заняты контейнерами — уцелеют
docker builder prune -f      # на всякий случай (обычно 0B)
df -h                        # место появилось?
```

Если место не появилось — ищем дальше (пришлите вывод):

```bash
du -sh ~/scoresbox/backups   # pg-дампы (ротация 30 дней)
sudo journalctl --disk-usage # системные логи
sudo du -sh /var/log/* | sort -h | tail -5
```

Затем: GitHub → Actions → ран CD **v1.0.51** → **Re-run failed jobs**.

## 2. Профилактика — deploy.sh v1.0.52 (файлы рядом)

- `scoresbox-2026-10-07-diskfix52-deploy.sh` — полный новый
  `scripts/deploy.sh`;
- `scoresbox-2026-10-07-diskfix52.diff` — дифф против прежней версии
  (ваш `scripts/deploy.sh` совпадает строка в строку с той, от которой
  сделан дифф — применится чисто; если нет — правьте по диффу глазами).

Что добавлено:

| # | Блок | Поведение |
|---|---|---|
| 0 | Чистка старых тегов ДО пулла | храним ровно 2 тега: новый + предыдущий РАБОЧИЙ (цель отката); остальное — `docker rmi` |
| 0.1 | Диск-преффлайт | < 3 ГБ → чистка dangling → всё равно мало → СТОП за 5 секунд с подсказками (не 10 минут качать и упасть) |
| 0.2 | Пулл с диагностикой | «no space left on device» распознаётся: чистка + повтор (не слепой ретрай 20с); сетевой обрыв — прежний ретрай; выход пулла стримится в лог CI |
| 3 | Финальный prune | без no-op label-фильтра — чистит реально висящие dangling |

## 3. Применить как v1.0.52 (в вашем клоне, PowerShell)

```powershell
# файл из чата уже скачан в Downloads:
Copy-Item "$HOME\Downloads\scoresbox-2026-10-07-diskfix52-deploy.sh" scripts/deploy.sh -Force
# проверьте дифф, если хотите:
git diff scripts/deploy.sh

# поднимите версию в package.json: "version": "1.0.52"
git add scripts/deploy.sh package.json
git commit -m "fix(deploy): v1.0.52 diskfix52 — чистка старых тегов образов до пулла, диск-префлайт 3ГБ, ретрай пулла с распознаванием no-space (не слепой 20с), финальный prune без no-op label-фильтра"
git push origin main
git tag v1.0.52 && git push origin v1.0.52
```

После деплоя: в логе появятся строки «чистим старый образ: …» — это
ожидаемо; health → 1.0.52. Проверка профилактики: `docker images` на
VPS — должно оставаться 2 тега приложения (1.0.51/1.0.52 и предыдущий).
